Gesture-Gated Browser API Test Suite

← Back to Landing Page

Every probe below must be triggered by an explicit button click. Browsers block permission prompts, device pickers, and media access when they are called without a live user gesture. A Pass means the API was reachable and the gesture-gated call resolved or rejected in a way that proves the gate exists (for example, a permission prompt appeared and was denied by you). A Partial means the API exists but the call could not complete (usually permission denied or no device available). A Fail means the API is absent in this browser.

Media Capture
